# 영문 Vantage Master V2 정적 분석 · 2026-10-23

원본 실행 파일을 실행하지 않고 PE 코드와 정수 표를 읽어 웹 엔진에 반영했다. 피해·OA·마나·이동·사거리의 아래 경로를 추적했으며, **원작 전체 AI와 모든 부가 규칙을 복원한 것은 아니다**. 테스트 통과는 웹 구현의 회귀 검증이며 원작 실행 결과와의 전수 비교가 아니다.

- 도구: `scripts/analyze-vm-exe.py`, pefile, Capstone x86 32비트. 원본 파일은 읽기 전용으로 다룬다.
- 추출: `scripts/export-v2-reference.py` → `src/v2-reference.js`의 `V2_RULE_TABLES` 및 맵 명암 필드. 입력 해시가 다르면 중단한다.

분석 도구의 pefile/capstone은 `.reference/analysis-tools`에 설치한다. 실행 파일·DAT·전체 디스어셈블리는 배포/리뷰 키트에 포함하지 않는다.

### 피해와 회복

물리 행동은 AT−DF, 마법 행동은 MAT−MDF를 사용한다. 여기에 행동 power, 속성 표, 방향 오프셋을 더해 `score`를 얻는다. 방향은 반올림한 육각 방향이 아니라 원본의 배가 X 좌표와 부등식으로 구분한다. 오프셋은 4/5/7/8이며, 범위 마법은 시전자 대신 효과 중심을 기준으로 한다.

```text
raw = damageTable[score]
damage = min(10, floor((trunc(raw * terrainPercent / 100) + 127) / 256))
healing = ceil((damageTable[MAT + power + 5] + 127) / 256)
```

피해는 0이 가능하다. 높이를 직접 더하는 기존 피해 보정은 제거했다. 예: score23 → 평지4, 마석3. 회복은 대상 최대 HP에서 잘린 실제 회복량만 적용한다. 표 범위를 벗어난 사용자 정의 값은 양 끝으로 제한한다. 이는 웹 안전 처리이며 원본의 범위 밖 메모리 접근을 모방하지 않는다.

### 시간·경제

```text
OA = floor(((30 + 이동여부*15 + action.oaExtra) * speedScale[SPD] + 128) / 256)
MP 수입 = (2 + 소유 마석 수) * 현재 마스터 MAT
유지비 = sum(trunc(정령 소환비 / 8))
```

SPD12 대기26분, SPD10 대기30분·이동대기45분·이동공격60분. 초기 배치와 소환 직후는 기본45에 속도 배율을 적용한다. 파산 시 비싼 정령 우선 규칙을 제거하고 소환 순서로 처리한다.

### 이동·사거리

물리 판정 높이는 MP 타일의 보조 높이(byte97)이고 그림 높이(byte96)와 다를 수 있다. 지상은 단차 1까지 이동하고 오르막은 비용1을 더한다. 비행은 높이 제한을 받지 않지만 물 위 착지는 불가하다. 원본 127 이동 비용은 통과 불가다.

궤적0/3은 `거리 + trunc(abs(높이차)/2)`로 판정하고 중간 장애물 검사를 생략한다. 곡사는 `거리 + trunc((목표높이−시작높이)/2)`, 직사는 절대 높이차를 쓴다. 육각 경계선을 지나는 광선은 양쪽 칸을 검사한다. 곡사의 부동소수점은 원본의 저장된 float32 중간값을 반영했으나 x87 연산의 모든 경계값까지 동일함을 증명한 것은 아니다.

## 매뉴얼과 화면

[공식 Information Window](https://www.falcom.co.jp/vantage/manual/manual4.html)의 Present Time, MP, The standing place를 대조했다. 매뉴얼은 효과의 의미를, 실행 파일 표는 세부 수치를 뒷받침한다.

| 지형 | 현재 반영 |
| --- | --- |
| 마석 | 행동 확정 시 점령, 떠난 후 소유 유지, 수입 증가, 피해30% 감소, 아군 소유 칸에서 행동 시작 HP+1 |
| 수풀/갈대 | 피해20% 감소, 이동 타입별 추가 비용 |
| 물 | 깊이에 따라 피해10/20/25% 감소, 이동·착지 타입 검사 |
| 부유 발판 | 코드6을 물과 별도 표시, 보행 착지 가능, 수위 변화 시 표시·판정 높이 함께 변경 |
| 사막/눈 | 보행 이동 비용 증가 |
| 습지 | 보행1 진입 불가, 수영/보행2 비용 구분, 방어 감소 없음 |
| 독 늪 | 행동 종료 피해 적용; 정확한 원작 피해 시점은 추가 확인 대상 |

마석 회복의 정확한 시작/종료 순서와 침수 피해 조건 전체는 이번 정적 분석 완료 범위에 포함하지 않는다. 수위 변화량2·침수 기준 수면 계산은 임시 모델을 유지한다. 이번 수정은 수위 변경 후 `runtimeTerrainCode/runtimeHeight`를 판정에 연결하고 만료·저장 복구 시 원본 필드로 돌아오도록 보완한 것이다.

시각은 아침04:00~07:59, 낮08:00~15:59, 저녁16:00~19:59, 밤20:00~03:59. 맵 고정 명암과 시각을 별도 표시한다. MP는 양 팀에 파랑 현재/노랑 수입/빨강 유지비를 표시하며, 숫자·순변화·다음 정산도 제공한다. 모바일 유닛 카드에 서 있는 지형, 피해 감소, 이동 비용, 착지 여부를 표시한다.

[공식 Using Sub Command](https://www.falcom.co.jp/vantage/manual/manual5.html)의 범위 구분에 맞춰 이동, 현재 공격/마법, 이동 후 공격/마법, 확정 전 효과 범위를 구분한다. 실제 판정 함수를 공유하며 범위 마법의 아군 피해를 확인 후 시전한다. 원작 전체 메뉴 구성이나 단축키를 그대로 재현한 것은 아니다.

## 남은 차이와 검증

- **AI:** 피해·회복·사거리·OA를 새 엔진으로 평가하고 원본 위치 평가 일부를 사용한다. 원본의 후보 열거·가지치기·다단계 상태 복사 및 전체 가중치는 미복원. 현재 웹 전략 AI를 원본 AI라고 부르지 않는다.
- SAT 임계값/획득량, 최초 클리어 XP, 보상 순서, 최대 소환6, 캠페인 분기, 수위 지형 전파, 반격의 모든 예외는 추가 분석 대상이다.
- 저장 형식5 및 `vt-battle-v5`로 분리한다. 이전 전투 저장은 자동 변환하거나 삭제하지 않는다. 원정 진행은 유지한다.
- `tests/exe-rules.test.js`: 정수 경계, 지형/이동, 수위 후 판정·복구, 파산 순서, 상태 OA, 직사 장애물, 범위 미리보기 회귀 검사.
- 자동 검사79개, 실험실35개 통과. 실험실은 회복의 이전 고정값2를 추출된 MAT11/power2 회복3으로 정정한다. 30개 맵의 제한된 AI 행동·재현 검사는 전체 캠페인 성공률을 뜻하지 않는다.
- 새 UI의 브라우저 육안 검증은 로컬 페이지 연결 및 CDP 시간 초과로 완료하지 못했다. 모바일 실기기 검증도 남아 있다.
