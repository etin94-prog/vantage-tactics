# 원본 미디어 적용 · 2026-10-23

사용자가 제공한 `.reference/VMO_WIN`의 Vantage Master V2 / Vantage Master Online 파일에서 변환했다. YouTube나 외부 사이트에서 음악·스프라이트를 다운로드하지 않았다. 원본 게임 리소스의 제작자는 Nihon Falcom이며, 웹게임이 제작한 원본 리소스로 표시하지 않는다.

## 실제 적용

- 마스터 27명, 정령 24종. 아군·적군 2종씩 총 102개 PNG atlas.
- 캐릭터별 6방향 × 3프레임 걷기, 공격. 마스터는 시전도 사용한다.
- 정령 시전 슬롯은 DATA03의 배열이 DATA01과 같지 않다. 잘못된 정령 이미지 대신 자신의 기본 자세와 기존 웹 효과를 사용한다.
- 단독 투사체만 있는 공격 프레임은 기본 자세를 합성해 캐릭터가 사라지지 않도록 했다.
- 기존 PNG/WebP 커스텀 이미지는 원본 도트보다 우선한다. 커스텀 제거 시 기본 도트로 복귀한다. 능력치·좌표·행동 판정은 변경하지 않았다.
- `CR000GM`~`CR019GM` 중 원본에 존재하는 MIDI 19곡(009 없음). gzip으로 보관하며 선택한 곡만 해제·해석한다.
- DATA13 슬롯 0~6의 실제 WAV 효과음 7개. 턴·점령·공격·소환·회복·시전·소멸에 연결했다.
- 소리 기본값은 꺼짐. 사용자 클릭 후 재생하며 곡 선택, BGM/SFX 개별 음량, 백그라운드 일시정지, 최대 음악 64음·효과음 8개 동시 재생을 지원한다.

## BGM 튜닝 · 2026-10-23

19곡 모두 같은 개선 합성기를 사용한다. 날카로운 기본 톱니파·사각파를 제한된 배음의 악기군별 음색으로 교체하고, 음의 시작·감쇠·종료를 부드럽게 했다. 킥·탐·하이햇·심벌·스네어 계열을 구분하고, 저음 EQ·고음 필터·짧은 스테레오 잔향·다이내믹 압축을 적용했다. 음이 많이 겹치는 곡에는 악보 기반 여유 음량을 확보한다. 효과음에는 BGM EQ나 잔향이 적용되지 않는다.

상단 ☷ → 음악과 효과음에서 다음을 조절한다.

- 추천 음색: 편안한 전술 / 선명한 전투 / 부드러운 밤.
- 곡별 음색 밝기, 저음 온기, 공간감, 재생 속도(75~125%), 음량 보정.
- 건반·벨, 기타·하프, 베이스, 현악·패드, 금관, 목관, 신시사이저, 드럼의 음량.
- 현재 곡 자동 저장, 19곡 전체 적용, 현재 곡 기본값 복원. 설정은 같은 기기·브라우저에 저장된다.

원곡 음표와 기본 템포 데이터는 보존한다. 재생 속도 조절은 재생 시에만 적용하며, 미리 예약한 약 180ms의 음은 이전 속도를 유지할 수 있다. 각 곡을 수작업으로 재편곡한 것은 아니며, 128종의 실물 악기 샘플을 사용하지 않는다.

## 동일하다고 주장하지 않는 부분

MIDI는 음표·템포·프로그램 번호·기본 음량/팬·서스테인을 읽지만, 원본 GM 음원 뱅크나 녹음 파일을 사용하지 않는다. 간단한 브라우저 합성기로 연주하므로 악기 음색·드럼·RPN 피치벤드 범위와 지속 중인 피치벤드·CC7/CC11 변화를 반영한다. 피치 이벤트는 5ms, 음량 이벤트는 20ms 구간으로 압축하며 CC1 비브라토 등 나머지 컨트롤러는 미지원이다. 최대 12초의 음 길이와 동시발음 제한도 있다.

전장별 자동 음악은 010~019를 순환하는 웹 임시 배정이다. 효과음 0~6의 원작 상황별 배정도 검증하지 않았다. 곡 제목은 확인하지 않아 UI에는 순번으로 표시한다. 원본과 같은 장면에 같은 음악·효과음이 나오는 완전 복원은 아니다.

SYSPAL/CHRPAL의 기본 팔레트를 사용했다. 파일에 없는 런타임 발광색 인덱스 100~127은 웹 그라데이션으로 재구성했다. 도트 조립은 검증했지만 6방향 매핑·걷기/공격/시전 속도는 원작 대조가 더 필요하다. 정령 전용 시전/사망 연출과 원본 맵 배경 타일, 오프닝 영상은 이번에 복원하지 않았다.

## 변환과 빌드

`scripts/export-reference-media.py`는 Pillow가 있는 Python에서 실행한다. 입력 DAT는 LB 오프셋 표와 기존 `read-vm-reference.py`의 압축 해제로 읽는다. CH는 24×12 픽셀 조각, CP는 프레임별 4열×8행 타일 참조다. CP는 열 우선·아래 행 우선으로 해석한다. 파일 해시와 캐릭터 슬롯 대응은 `reference-media-manifest.json`에 기록했다.

```powershell
python scripts/export-reference-media.py
npm test
npm run check
npm run build
npm run lab:test
npm run lab:kit
```

개발용 모듈은 `src/reference-media.js`, 배포용 공용 파일은 `assets/reference-media.js`다. `play.html`과 `lab.html`을 옮길 때 `assets` 폴더도 함께 옮겨야 한다. HTML마다 5MB 에셋을 중복 삽입하지 않고 공유한다. 기본 저장 데이터에는 도트가 복제되지 않는다. 원본 EXE·DAT는 배포하지 않는다.

## 검증

87개 Node 테스트: 기존 전투/전략 테스트와 MIDI 템포·running status·서스테인·잘린 파일 거부, 19곡 전체 해석, 캐릭터 51종의 2팀 atlas 크기, 커스텀 우선순위, 비동기 음악 변경/중지 경쟁 조건, 곡별 설정 보존·전체 적용, 값 검증, 음량 여유, 속도 변경을 검사했다. 실험실 35개 실험도 별도로 실행한다. 테스트 통과는 원작 음색·연출 동일성의 증거가 아니다.

OfflineAudioContext로 각 곡에서 음표 시작 강도가 가장 밀집한 6초 구간과 잔향을 렌더링했다(44.1kHz, 2채널, 각 8초). 19곡 모두 유한한 비무음 출력이고 클리핑 샘플은 0개였다. 인접 샘플 차이 RMS / 신호 RMS 지표는 17곡에서 낮아지고 2곡에서 소폭 높아졌다. 이는 고역 변화의 제한적 지표이며 청취 평가나 전체 곡 검사를 대신하지 않는다. 비교 결과는 `audit-evidence/audio-render-20261023.json`에 있다. 오프라인 검사는 미래 음을 한꺼번에 예약하므로 실시간 64음 상한을 우회한다.

브라우저에서 도트 표시, 음악 켜기·끄기, 곡 변경, 효과음 미리 듣기, 음량 조작을 확인한다. 자동 검증은 실제 휴대폰 스피커의 음질이나 원곡 청취 비교를 대신하지 않는다. 390px 폭 화면으로 UI 배치도 확인한다.


## Claude c5a9e2 후속 수정 · 2026-10-23

RPN 0/0의 반음·센트 범위를 적용하고, 음 도중 피치와 음량 변화를 예약한다. CC7/CC11은 제곱, 벨로시티는 1.7승으로 변환한다. 음량이 0에서 시작하는 스웰도 생성하며, 밀집도 계산은 음의 최대 컨트롤러 값을 고려한다. 밝기는 음별 필터와 배음 구성에 연결한다. 킥·베이스를 감쇠하고 BGM에 85Hz 하이패스를 추가했으며 하이햇/심벌은 3kHz/2.4kHz 대역으로 조정했다. **이 음색 선택의 실제 청취 평가는 하지 않았다.**

BGM 출력 보정14배, 마스터 압축 threshold−3dB/ratio20/knee0, 최종 출력0.8을 사용한다. 효과음별 감쇠는 turn−16dB, summon−14dB, capture/attack/heal−10dB, spell−8dB, down−4dB다. 기존 슬라이더·음소거·곡별 튜닝 값은 그대로 유지하고 `audioMixVersion:2`와 `previousAudioMix`를 기록한다. 슬라이더 수치는 같아도 출력 음량이 이전 빌드와 달라진다. 자동으로 소리를 켜지는 않는다.

프리셋은 밝기·저음·잔향·금관·드럼·신스만 변경하고, 속도·곡 음량·다른 악기 비중을 보존한다. 일치하는 프리셋이 표시된다. 효과음 디코드 실패는 캐시에서 제거하여 다음 이벤트에서 재시도하고, 3회 연속 실패 후 소리 재활성화까지 멈춘다. 오류는 토스트로 분리한다. 시야 밖 행동은 렌더러와 같은 기준으로 음소거하며 아군 턴만 알린다. 음악 정지는 음별 30ms 페이드 후 정지한다. 첫 재생 리드인은 120ms로 단축하지만 원곡 반복 길이와 끝 무음은 보존한다.

설정창 헤더를 고정하고 닫기 버튼을 44×44px로 확장했다. 종료 전투 결과창은 열려 있는 설정창을 닫은 뒤 표시한다. 오디오 중단·재개 실패에는 상태와 재시도 안내를 제공한다. 실제 iOS interrupted 동작은 미검증이다.

검증 자료: `../test-results/codex-audio-20261023-c5a9e2/`. 클로드 원본 보고서·스크립트는 보존했다. 결함 재현6개는 수정 전6개 실패 → 수정 후6개 통과. 전체87개 및 실험실35개 통과. 19곡의 동일한 밀집6초 구간을 8초로 렌더한 기본 BGM RMS는 −25.8~−18.7dBFS(이전 −44.7~−39.0). 기본·100% BGM에서 클리핑0, 효과음 단독 peak−19.9~−14.3dBFS. 이는 해당 구간 검사이며 전체 곡·모든 설정 조합의 무클리핑 보장이 아니다. 효과음 측정 스크립트에도 새 트림을 명시적으로 반영했다.

57회 스케줄러 모의 실행(19곡×75/100/125%)에서 최대54음, 75% 최대45음, 64음 제한 누락0. 실제 브라우저에서19곡 시작·효과음7종·연속 토글·설정 새로고침 보존을 확인했다. 390×844·844×390 모의 화면을 검사했으나 실기기를 검사하지 않았다. 실제 소리를 듣거나 같은 체감 음량의 A/B 청취를 하지 않았으므로 음질 개선의 주관적 판정은 보류한다.

reduced-motion은 로드 시 한 번 읽으며 유닛 흔들림·이동 보간·CSS 전환을 줄인다. 소환 링·투사체·피해 숫자 효과는 유지한다. 운영체제 설정 변경은 새로고침 후 반영된다.
