# 실기기 체크리스트 · 2026-10-24

대상 빌드: 이 문서와 함께 배포된 게임(https://etin94-prog.github.io/vantage-tactics/). 오늘 바뀐 것: 공격 예측 창, 길게 누르기 정보, 세로 상단·하단 압축, 한 줄 안내, 작은 화면 줌 버튼, 글자·버튼 크기. 이전 인계에서 남은 소리·진동 항목도 함께 본다.

기록 방법: 항목마다 **○(정상) / △(어색함) / ✕(안 됨)** 와 한 줄 메모. 폰 기종·OS·브라우저를 맨 위에 적는다. ✕·△ 는 가능하면 스크린샷.

시작 전: 처음 한 번은 새로고침해 새 버전을 받는다. 상단 1줄에 `MP 62/62 적 32` 같은 짧은 MP 표시가 보이면 새 버전이다.

## A. 화면 배치 (세로)

| # | 확인 | 기대 결과 |
|---|---|---|
| A1 | 첫 화면 위쪽 | 1줄: V·맵 이름·MP·⛶·☰ / 2줄: 시각 + 행동 순서 카드. 노치·상태 표시줄에 글자가 가리지 않음 |
| A2 | 아래쪽 | 1줄: 유닛 요약 + 정령·전황·내 유닛 / 2줄: 행동 버튼 6개. 홈 표시줄(아이폰 아래 막대)에 버튼이 겹치지 않음 |
| A3 | 글자 | 행동 순서 카드 이름·숫자, 유닛 요약 글자가 돋보기 없이 읽힘 |
| A4 | 주소창 | 스크롤·회전으로 주소창이 접히거나 펴질 때 화면이 잘리거나 빈 띠가 생기지 않음 |
| A5 | MP 누르기 | 상단 MP 를 누르면 수입·유지비 상세가 펼쳐지고, 다시 누르면 접힘 |
| A6 | 작은 폰(높이 짧은 기종)만 | 줌 −/+ 없이 ⌖ 하나만. 두 손가락으로 확대·축소 됨 |

## B. 조작

| # | 확인 | 기대 결과 |
|---|---|---|
| B1 | 파란 칸 탭 | 바로 이동, 하단 첫 버튼이 '이동 취소'로 바뀜 |
| B2 | 공격 가능한 적 한 번 탭 | **바로 공격하지 않고** 예측 창: 예상 피해, 상대 HP 전→후, 반격 피해 또는 '반격 없음' |
| B3 | 예측 창 위치 | 창이 내 유닛과 대상 적을 가리지 않음(필요하면 화면이 살짝 움직임) |
| B4 | 같은 적 다시 탭 / '공격 확정' | 공격 실행. 실제 피해·반격이 예측 숫자와 같음 |
| B5 | 예측 중 '취소' 또는 다른 칸 탭 | 예측 창 닫힘, 공격 안 함 |
| B6 | 전장 칸 길게 누르기(약 0.5초) | 지형·높이·받는 피해(유닛 위면 HP·예상 피해) 카드. **글자 선택·돋보기·메뉴가 뜨지 않음** |
| B7 | 길게 누른 뒤 손 떼기 | 이동·공격 같은 행동이 일어나지 않음. 다음 탭에 카드 닫힘 |
| B8 | 드래그·두 손가락 | 드래그로 지도 이동, 두 손가락으로 확대. 이때 길게 누르기 카드가 뜨지 않음 |
| B9 | 소환 | 정령 선택 → 보라색 칸이 지형과 확실히 구분됨 → 탭하면 소환 |
| B10 | 하단 안내 한 줄 | 모드마다 짧은 문구 한 줄(이동: '파란 칸으로 이동 · 길게 누르면 정보'). 두 줄로 넘치지 않음 |
| B11 | 정령·전황·내 유닛 탭 | 각각 정령 목록 / 전황 기록 / 내 유닛으로 카메라 이동 |

## C. 소리·진동 (이전 인계에서 남은 항목)

| # | 확인 | 기대 결과 |
|---|---|---|
| C1 | 메뉴에서 소리 켜기 → 다음 스테이지 | 소리 켜짐 유지 |
| C2 | 다른 앱으로 갔다 돌아오기 | 음악 다시 나옴(안 나오면 화면 한 번 터치 후) |
| C3 | 새로고침 → 첫 터치 | 첫 터치 뒤 음악 시작 |
| C4 | 공격·반격·마법 | 피해 숫자가 뜨는 순간 타격음. 0 피해도 접촉음 |
| C5 | 음악 0·효과음만 / 효과음 0 | 각각 그 소리만 꺼짐 |
| C6 | 소리 끄기 → 새로고침 | 꺼진 상태 유지 |
| C7 | (Android) 타격 진동 | 공격·반격·전투 불능에 짧은 진동. 설정에서 끄면 없음. 길게 누르기에도 아주 짧은 진동 |

iPhone 은 웹 진동을 지원하지 않는다 — C7 은 Android 만.
