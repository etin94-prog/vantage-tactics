# 모바일 기본 인터페이스 · 2026-10-23

게임은 960px 이하에서 모바일 전투 화면을 사용한다. 전장, 자원 요약, 선택 유닛 HP, 행동 버튼을 화면 안에 고정하고 페이지 전체를 스크롤하지 않는다. 정보 패널과 설정창 내부만 스크롤한다.

- 세로: 상단 행동 순서·시각·MP, 중앙 전장, 하단 유닛 요약·6개 행동·정령/전황/내 유닛/메뉴.
- 가로(높이 540px 이하): 행동과 메뉴를 오른쪽 182px 패널로 이동한다.
- 정령 목록은 하단 패널의 큰 카드와 속성 필터를 사용한다. 소환 비용·유지비·공격·기본 사거리·고유 마법 사거리를 표시한다. 선택에 성공하면 패널을 닫고 소환 위치를 고른다. 잠김·MP 부족 등은 기존 규칙으로 검사한다.
- 유닛 요약을 누르면 능력치·방향·서 있는 지형을 확인한다. 전황에서 양측 MP의 파랑/노랑/빨강 막대와 기록을 확인한다. 상단 MP 요약도 펼칠 수 있다.
- 이동 후 같은 자리에 이동 취소 버튼이 나타난다. 카메라 버튼은 44px, 주요 행동은 높이 56px이다. 320px 폭에서 행동 버튼 너비는 46.5px다.
- safe-area 여백과 동적 뷰포트 높이(dvh)를 사용한다. PC 너비로 돌아가면 기존 좌우 패널과 행동 버튼을 원위치로 옮긴다.

`src/mobile-ui.js`는 기존 DOM 컨트롤을 이동한다. 별도 전투 상태나 복제 ID를 만들지 않는다. 패널이 열려 있는 동안 AI 실행과 결과창 표시를 유예하며, 닫으면 재개한다. `build.mjs`가 새 모듈을 `play.html`에 포함한다.

## 정령 교전 피드백 개선 · 2026-10-23

유닛 아래에 현재 HP/최대 HP 숫자를 표시한다. 피해 숫자는 화면 확대율에 관계없이 같은 글자 크기로 2.2초 표시하며, 반격·피해 없음·전투 불능을 구분한다. 하단 최근 교전 결과는 각 대상의 실제 감소량과 HP 전후 값을 다음 피해 이벤트까지 유지한다. 작은 화면(높이700px 미만)은 요약을 기본으로 표시하고 눌러 상세를 펼친다. 시야 밖 피해는 결과 패널에 표시하지 않는다.

피해 이벤트에 판정 당시 HP 스냅샷을 기록하며 피해 공식은 바꾸지 않았다. 오버킬은 실제 잃은 HP만 표시한다. 다음 AI 행동 전 최소2초 읽을 시간을 두고, 결과 패널 개폐로 전장 높이가 달라져도 카메라가 다음 행동자로 튀지 않게 했다.

검증: 정령 공격·반격 양쪽 HP10→9, 반격0, HP1→0 전투 불능을 브라우저에서 확인. 320×568 화면에서 요약과 행동 버튼이 화면 안에 유지된다. 추가 회귀 검사3개(교전 HP 스냅샷, 0/치명 피해, 카메라 유지) 포함 전체90개 통과. 증빙은 `test-results/combat-feedback-20261023/`. 실제 휴대폰 미검증. 이 추가 수정은 145b24c 이후 교전 피드백 개선 배포에 포함한다.

## 전체화면 · 범위 버튼 정리 · 2026-10-23

상단 ⛶ 버튼으로 Fullscreen API를 요청한다. 브라우저가 허용하면 주소창을 포함한 탐색 UI를 숨기며, 종료 버튼과 브라우저 자체 종료 시 버튼 상태를 동기화한다. 지원하지 않거나 요청이 거절되면 홈 화면 추가 방법을 안내한다. 안내 중에는 전투 AI와 결과창을 유예한다. 자동 전체화면 진입은 하지 않으며 사용자의 버튼 입력을 사용한다.

manifest.webmanifest의 상대 경로 scope/start_url, standalone 표시, 192/512 PNG 아이콘 및 Apple 웹 앱 메타 설정을 추가했다. iPhone은 Safari 공유 → 홈 화면에 추가 → 웹 앱으로 열기(표시되는 경우)를 통해 실행한다. 기존 브라우저 탭의 URL 표시를 CSS로 강제로 제거할 수는 없다. 홈 화면 설치와 실기기 주소창 숨김은 미검증이며 오프라인 실행은 제공하지 않는다.

모바일 범위 보기 버튼은 전장 상단의 카메라 조작 줄로 이동했다. 시각 크기는 약 62×30px, 터치 높이는 36px이다. 펼쳤을 때만 설정 패널이 나타나며 PC 크기에서는 기존 위치로 복원한다. 불필요한 마법 선택 줄이 숨김 속성을 무시하던 CSS도 수정했다.

검증: 전체 93개 테스트 통과(전체화면 진입/종료·실패 안내·설치 실행 상태 검사 포함), 빌드/구문 검사 통과. 내장 Chromium에서 버튼 상태 전환, 320×568·390×844 세로 및 844×390 가로, 1366×900 PC 복원을 확인했다. 증빙: test-results/mobile-fullscreen-20261023/. 휴대폰 실기기 및 Safari 미검증. 이번 변경은 419f319 이후 전체화면·범위 버튼 개선 배포에 포함한다.

참고: https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen / https://support.apple.com/en-gb/guide/iphone/iphea86e5236/27/ios/27

## 공격·반격 표시 순서와 타격 진동 · 2026-10-24

현재 엔진은 공격 피해 적용 후 생존한 대상이 인접·방향·사거리·상태 조건을 만족하면 반격한다. 이는 현재 구현의 설명이며 원작의 모든 반격 예외가 검증됐다는 뜻은 아니다. 공식 manual3/manual5에는 세부 타격 순서나 치명타 이후 반격 여부가 명시되지 않았다. EXE 정적 분석 문서의 반격 예외 미확정 항목을 유지한다. 이번 변경은 피해·반격 판정·OA를 변경하지 않았다.

기존 렌더러가 한 번에 받은 공격/반격 피해를 같은 시작 시각에 표시하던 문제를 수정했다. 공격은 즉시, 반격 모션은 450ms, 반격 피해는 650ms에 시작한다. 이 수치는 원작 추출값이 아닌 읽기 편한 웹 연출 값이다. 반격 전까지 공격자 HP는 이벤트의 hpBefore로 표시하고, 피해 숫자·HP·교전 결과·효과음·진동을 해당 시점에 갱신한다. 반격으로 쓰러질 유닛도 타격 전까지 전장에 남는다. 교전 중 다음 행동 입력을 막고, 사망 연출 뒤 결과창을 표시한다. AI 교전 후 카메라가 다음 유닛으로 미리 옮겨가지 않도록 유지한다.

GameHaptics는 기본 켜짐이며 음악/효과음 음소거와 독립적이다. 메뉴 → 음악·효과음·진동에서 끄기/켜기 및 진동 테스트가 가능하며 설정을 저장한다. 실제 피해가 양수일 때 일반 타격20ms, 반격30ms, 전투 불능35/45/55ms(진동/쉼/진동)를 요청한다. 100ms 안의 광역 타격은 합쳐 과도한 진동을 막는다. 0피해·시야 밖·비활성 탭·사용자 입력 이전에는 진동하지 않는다. 끄기/화면 숨김/새 전투 시 현재 진동을 취소한다. API 미지원·거절·예외는 전투를 중단시키지 않는다. API 지원이나 true 반환은 물리적 진동 발생을 보장하지 않으므로 실기기 확인은 별도다.

검증: 전체96개 자동 검사, 실험실35개 통과. 추가3개 검사는 진동 상태/0피해/광역 합치기, 미지원/거절, 반격 모션→피해→사망 및 HP 스냅샷 순서를 검증한다. 후속 UI 안내 수정 후 관련7개 재검사·빌드·구문 검사 통과. 내장 Chromium 390×844 교전 fixture에서 공격 약10ms/반격686ms, 공격자 HP10 유지→반격 HP9, 교전 결과 순차 추가 확인. 진동 끄기 저장 후 재로딩, 다시 켜기와 테스트 요청 안내, 콘솔 오류 없음 확인. 증빙 test-results/haptics-20261024/. 실제 소리 청취/휴대폰 진동 미검증. 로컬 빌드 반영이며 아직 공개 배포하지 않았다.

## 이동·카메라·표시 정리 및 내 차례 강조 · 2026-10-24

- HP 막대와 중복 HP 문구를 정리해 유닛 아래 숫자 배지 한 개만 남겼다. 이동 중 배지도 스프라이트의 보간 위치를 따른다. 피해 표시는 −N/반격 −N 한 줄로 표시하고, 스프라이트·다른 HP/피해 라벨과 겹치지 않는 슬롯에 배치한다. 매우 축소되거나 밀집한 경우 빈 공간이 없는 배지는 생략하며 상세 수치는 유닛 패널과 교전 결과에서 확인한다.
- 이동 이벤트에 실제 도달 가능 경로를 기록한다. 장애물 우회, 빙판 도착 이동, 포탈 점프와 이동 취소 경로를 보존한다. 기존 저장의 경로 없는 이동 취소는 점프 표시로 처리한다. 이동 비용과 판정 규칙은 바꾸지 않았다.
- 기본1배에서는 칸당 약260ms(최소280ms)로 경로를 따라 이동하고, 이동 완료 후 공격 모션→300ms 타격→800ms 반격 모션→1100ms 반격 피해 순으로 재생한다. 마법 피해는 이동 완료 후400ms에 표시한다. 이 값은 웹용 연출 값이며 OA나 피해 수치를 바꾸지 않는다. 프레임 정체 시 이동·후속 동작을 한 프레임에 건너뛰지 않도록 보정한다.
- 적이 행동하기 전650ms/속도 동안 해당 적을 따라가는 카메라를 보여주고, 이동·공격 중에도 행동 주체를 유지한다. 시야 밖 적은 추적하지 않는다. 전장 드래그/줌은 그 턴의 추적을 해제하고 다음 턴 준비 때 다시 추적한다. 화면이 숨겨지면 AI 실행을 멈추고 복귀 시 재개한다. 조작 잠금은 연출 완료 시 풀린다.
- 메뉴의 별도 '전투 연출 속도'에서0.75/1/2/3배를 선택하고 저장한다. 기본1배이며 이동·공격·반격·턴 대기를 함께 조절한다. 재생 중인 연출은 기존 속도로 끝내고 다음 연출부터 새 값을 사용한다.
- 아군 행동 유닛에 밝은 선택 링·상단 화살표·'내 차례'(이동 후 '행동 선택') 라벨을 표시한다. 다른 유닛을 관찰해도 실제 행동 유닛 강조는 유지한다. 하단 행동 안내에도 이름을 표시하고, 행동 순서의 동일 유닛 미래 항목까지 중복 강조하지 않는다. 동작 줄이기 설정에서는 맥동·부드러운 카메라 이동을 생략한다.

검증: 전체102개 자동 테스트 통과. 추가6개는 실제 경로/취소, 이동 후 공격 순서와 속도, 경로/포탈 보간, 라벨 충돌 방지, 적 카메라 추적, 프레임 정체를 검사한다. 후속 수정 후 관련12개 테스트와 빌드/구문 검사를 통과했다. 내장 Chromium에서390×844와320×568 표시, 기본1배 및0.75배 저장 후 재로딩, 한 개의 현재 순서 강조, 적 추적과 HP/피해 라벨 분리를 확인했다. 작은 화면에서 문서320×568, 하단 조작부 끝568px이며 콘솔 오류 없음. 증빙 test-results/presentation-20261024/. 실제 휴대폰 터치·진동은 미검증. 이번 변경과 직전 진동 변경은 아직 로컬 빌드이며 공개 배포 전이다.

## 타격음과 소리 설정 유지 · 2026-10-24

소리 켜짐 여부를 preferences.soundEnabled에 저장한다. 스테이지 전환과 페이지 재로딩 후에도 사용자의 켜기/끄기 선택을 유지한다. 재로딩 직후에는 브라우저의 자동 재생 제한에 따라 첫 화면 터치 또는 키 입력으로 재생을 시작한다. 비활성 화면에서는 일시 중단하고 복귀 시 재개를 시도한다. 재개 실패·대기 상태는 음소거로 바꾸지 않고 다음 사용자 입력에서 재시도한다. 브라우저가 resume 요청을 계속 대기시키는 경우에도 새로운 사용자 입력에서 resume을 다시 호출한다.
