# 모바일 UI·손맛 1–3단계 · 2026-11-17

사용자가 요청한 1–3단계를 개발 폴더에 구현했다. 배포하지 않았다. 공개본은 b44834b를 유지한다.

## 1단계: 조작 안정성

- 세로 주요 행동은 같은 턴·유닛·이동 상태·조작 가능 상태 안에서 유지한다. 행동 모드만 바뀌어도 버튼 종류가 바뀌지 않는다. 이동 취소는 기존 이동 자리에서 제공한다.
- 더보기는 전장 크기를 바꾸지 않는 위쪽 확장 방식이다. 접기 버튼 위치 유지, Escape로 접기 및 포커스 복귀.
- 비활성 행동을 누르면 조작부 바로 위에 기존 판정 이유를 표시한다. 새 판정을 만들지 않는다.
- 유닛 옆 중복 메뉴는 모바일 기본 끄기. 범위 보기의 '유닛 옆 행동 메뉴'에서 복구할 수 있다. 데스크톱 동작은 유지한다.
- 가로는 상세·기록·정보 탭 영역만 스크롤한다. 예측의 확정·취소는 아래에 유지하며, 예측 시 중복 행동 안내를 접는다.
- 확인: 더보기 전후 전장 높이 모두 610.5 CSS px. 844×390에서 확정 버튼 y329–373, 상세 스크롤 후에도 동일. 740×360에서 y299–343, 높이 44px, 가로 넘침 없음.

## 2단계: 전장 가독성

- 이동 중 보조 공격 범위의 채움을 옅게 하고 외곽선을 생략한다. 실제 공격 가능 대상 표식과 명시적 범위 관찰 기능은 유지한다.
- 높이는 행동 유닛·선택 유닛·가리킨 칸·조준 대상·이동 목적지 주변 중심으로 표시한다. 범위 보기의 '전체 높이 표시'로 전체 표시 가능, 브라우저 설정에 저장한다. 지형 높이 자체는 변경하지 않는다.
- 이동 경로는 `battle.reachable().parents`에서 읽은 경로를 점선으로, 목적지는 원으로 표시한다. PC 가리키기 및 모바일 길게 누르기로 확인한다. 이동 확정 규칙을 추가하지 않았다.
- NOW → 현재, 행동 순서 → '대기 후 28분' 형식, MP 다음 수입 → '18분 후'로 의미를 보강했다. 동일 예측의 반복 자동 스크롤을 줄였다.
- 확인: 높이 전체/주변 전환, 이동 범위 강조, 기존 경로의 목적지 일치, 세로·가로 회전 및 데스크톱 DOM 복귀.

## 3단계: 입력·타격·결과 피드백

- 행동 버튼에 짧은 눌림 피드백. 동작 줄이기에서는 새 변형·전환을 끈다.
- 기존 피해 이벤트의 접촉 순간부터 피해 숫자 최대 1.35배 → 220ms에 원래 크기. 프레임 수가 아닌 경과 시간 기준이다.
- HP 숫자 아래에 현재 HP 막대와 피해 잔상을 표시한다. 잔상은 120ms 유지 후 500ms까지 줄어든다. 숫자와 실제 HP 반영 시점은 기존 접촉 시점 그대로다.
- 피해 숫자의 반격 표식을 유지하고 HP 0에는 처치 표시를 추가했다. 기존 타격광·효과음·일반/반격/처치 진동은 동일 접촉 이벤트 경로를 유지한다. 새 진동·음원은 추가하지 않았다.
- 기존 피격 연출에서 공격자의 타일 높이 대신 유닛 좌표를 읽어 NaN 이동량이 생기던 문제를 수정했다. 실제 타일 높이를 사용하고 실제 좌표계로 접촉~319ms 회귀 테스트를 추가했다. 엔진 판정은 그대로다.
- 동작 줄이기는 숫자 크기 1, 움직이는 HP 잔상 0이며 피해 숫자·현재 HP·반격·처치 정보는 남긴다.
- 공격 960ms / 접촉 360ms, 마법 1000ms / 접촉 480ms, 반격 1100ms, 맞기 320ms 변경 없음. 추가 입력 잠금·전투 시간 연장 없음.
