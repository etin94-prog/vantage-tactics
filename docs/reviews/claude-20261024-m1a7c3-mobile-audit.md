## 조작 관찰 (390×844 실플레이)

- 이동: 파란 칸 탭 → 즉시 이동, 하단 첫 버튼이 '이동 취소'로 바뀜.
- 소환: 바텀시트 2열 카드. 잠긴 정령이 사용 가능한 정령과 섞여 표시. 배치 가능 칸(보라) 강조가 지형색과 거의 구분되지 않음.
- 적 턴: 자동 진행, 카메라가 적을 추적. 진행 중 하단에 '이동·전투 연출 중…'.
- 길게 누르기 없음 → 터치에서 타일·유닛 정보는 하단 '상세' 경유만 가능.

## 구조 장애물 (UI 작업 전 처리 대상)

1. main.js 62KB, 함수 하나가 한 줄, 전역 let 상태, update() 가 패널을 innerHTML 로 전체 재생성 → 선택→미리보기→확정 상태 흐름과 전환 애니메이션을 넣기 어려움.
2. mobile-ui.js 가 PC 패널 DOM 을 시트로 옮기는 방식, 960px 기준 matchMedia 가 세 곳에 하드코딩.
3. hover 의존 입력(툴팁·예상 피해·이동 후 사거리).
4. Canvas 매 프레임 전체 재그리기, 30fps 상한, CSS 는 고정 px 약 1,027회·rem 0회(UI 배율 옵션 불가).
5. build.mjs 가 정규식으로 import 를 지우고 이어 붙임(모듈 수동 등록, 이름 충돌 위험), 일부 테스트가 소스 문자열·Renderer 내부 필드에 묶임(audio-ui.test.js:7-9, review-regression.test.js:60-86). DOM/CSS 를 지키는 테스트는 없음.
