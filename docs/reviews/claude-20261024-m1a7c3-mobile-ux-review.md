# 모바일 조작·정보 표시 전반 검토 · 2026-10-24 (Claude)

대상: 로컬 빌드(9차까지, 공개 da6c405 + 9차 미배포분). 375×812(모바일 프리셋)·390×844·844×390 에서 첫 실행(저장 없는 별도 주소)부터 전투·원정 지도·설정까지 화면을 열고 DOM 글자·크기를 읽었다. 코드는 바꾸지 않았다. 실기기 미검증.

판단 기준: 사용자 목표 — "원작의 전략적 요소를 활용해 게임을 즐길 수 있는가", 캠페인으로 시스템을 배우는 흐름, 상용 모바일 SRPG 수준의 조작 편의.

## 요약

전략에 핵심인 정보(행동 순서의 시간, 적 위협 범위, 상성, MP 정산 시점, 승리 조건)가 **존재는 하지만 숨은 창이나 PC식 양식 안에 있다.** 플레이어가 판단하는 순간(정령 고르기, 이동 칸 고르기, 대기 누르기)에 그 정보가 눈앞에 없다. 그다음 문제는 조작 중복·가림, 화면 흐름(첫 화면·원정 지도·설정), 개발용 문구 노출과 디자인 불일치 순이다.

| # | 현재 | 문제 | 제안 |
