## 검증 및 근거

- 전체 Node 테스트87개, Claude 재현6개, 실험실35개 통과. 구문 검사·로컬 play.html/lab.html 빌드 통과.
- 기본 설정 19곡 RMS: 이전 −44.7~−39.0 → 수정 −25.8~−18.7dBFS. 기본/100% BGM 렌더에서 클리핑0. 효과음 단독 peak −19.9~−14.3dBFS.
