## 3차 · 세로 하단 조작부 압축 + 예측 창 위치 (같은 날)

세로 모바일에서 `.mobile-dock` 을 그리드로 바꿔 1줄(44px) = 유닛 요약(초상·이름·진영·HP) + 아이콘 탭 3개(정령·전황·내 유닛, 각 46×44), 그 아래 행동 버튼 줄(56px)로 합쳤다. '메뉴' 탭은 상단 ☰ 와 같은 기능이라 세로에서만 숨김(가로 패널에는 유지). '상세 ›' 글자는 숨기고 요약 줄 전체가 그대로 상세 버튼이다. 전투 결과 패널은 요약 줄과 행동 줄 사이에 들어간다(접힌 상태 46px).

1차에서 만든 공격 예측 창이 작은 화면에서 대상·공격자를 가리던 문제를 고쳤다. 창 높이를 실측해 공격자와 대상의 화면 범위(스프라이트 위 72px·아래 34px × 배율)가 겹치지 않는 쪽(위/아래)에 띄우고, 양쪽 모두 겹치면 두 유닛을 빈 공간 가운데로 카메라를 옮긴다. 창 여백·숫자 크기를 줄이고, 화면 높이 700px 이하에서는 '한 번 더 누르면' 안내를 숨긴다.

| 화면 | 하단 조작부 | 캔버스 (2차 후 → 3차 후) | 가리는 것 없는 전장 |
|---|---|---|---|
| 390×844 | 158 → 111px | 69% → 75% | 60% → 65% |
| 320×568 | 158 → 111px | 55% → 63% | 37% → 45% |
| 844×390 | 변화 없음(의도) | — | 44% |

320×568 확인: 조준 시 카메라가 위로 옮겨져 아돌·규네포스가 예측 창 위에 보임, 예측 −8/HP 10→2/반격 −0 = 실제 −8/2/10·반격 0. 하단 조작부 버튼 44px 미만 0개. 콘솔 오류 없음.

## 4차 · 행동 안내 한 줄 (같은 날)

행동 안내를 `차례(hint-who) · 긴 설명(hint-long) · 짧은 설명(hint-short) · 이동 취소(hint-undo)` span 으로 나눴다. 세로 모바일은 짧은 설명만 한 줄(넘치면 …)로 보인다 — 차례는 상단 라벨·지도 '내 차례' 표식, 이동 취소는 하단 버튼이 이미 알린다. 가로·PC 는 기존 긴 문구 그대로(확인). 이름은 esc 처리.

짧은 문구: 이동 '파란 칸으로 이동 · 길게 누르면 정보', 공격 '붉은 테두리 적 선택 → 예측 확인', 소환 '<정령> · MP n → 남는 m · 보라 칸 선택', 마법 '<마법> · MP n · 대상 선택', 치유는 기존 문구.

| 화면 | 안내 높이 | 가리는 것 없는 전장 |
|---|---|---|
| 320×568 | 44 → 26px | 45% → 49% (276px) |
| 390×844 | 27 → 26px | 65% (변화 없음) |

320 에서 이동·소환 문구 잘림 없음 확인. 검사: `npm test` 111/111, `npm run check`, `npm run lab:test` 35/35, 빌드 통과, 콘솔 오류 없음.

320×568 이 60% 에 못 미치는 남은 몫: 전장 위 상단 조작 줄(범위 보기·제목·줌 버튼, 44px 오버레이)과 안내 26px. 줌 버튼을 빼면(핀치 줌으로 대체) 약 +44px 이지만 버튼 줌을 쓰는 사용자의 조작을 없애는 결정이라 사용자 판단 사항.

## 5차 · 작은 세로 화면 줌 버튼 (같은 날, 사용자 A안 선택)

높이 600px 이하 세로 화면에서 −/+ 줌 버튼(#zoom-out, #zoom-in)을 숨긴다. 확대·축소는 두 손가락(기존 핀치, review-regression 테스트가 보호)으로 한다. ⌖(#fit-btn)는 '전장 전체 보기'라 대체 수단이 없어 남겼다 — 4차 보고 때 ⌖ 를 '내 유닛 이동'으로 잘못 설명했고, 확인 후 바로잡았다. 390×844 등 높이 600px 초과에서는 세 버튼 모두 보임(확인).

320×568 결과: 상단 오른쪽 덮개가 버튼 3개(136×44) → 1개(44×44), 현재 행동 제목('아군 · 아돌 행동 선택')이 잘리지 않고 다 보임. 덮개(범위 보기·제목·⌖·안내) 면적은 전장 캔버스의 11%, 캔버스는 화면의 63% → 면적 기준 가려지지 않은 전장 약 56%. 기존 줄 기준(상단 줄 아래~안내 위) 수치는 49% 그대로다 — 그 줄은 버튼 사이가 투명이라 줄 기준은 보수적 수치다. 두 기준 모두 60% 미만.

검사: `npm test` 111/111, `npm run check`, `npm run lab:test` 35/35, 빌드 통과.
