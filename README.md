# Vantage Tactics · 소환사의 여정

브라우저에서 플레이하는 소환 전술 게임 0.2입니다.

[게임 플레이](https://etin94-prog.github.io/vantage-tactics/)

PC와 모바일 브라우저를 지원합니다. 소환사 18종, 네이티얼 24종, 30개 캠페인, 캐릭터 외형 커스텀을 제공합니다.

- 타일을 눌러 이동하고 도감에서 정령을 선택해 소환하세요.
- 드래그로 전장을 이동하고 두 손가락으로 확대·축소합니다.
- 마석 점령으로 마나를 확보하고 적 소환사를 쓰러뜨리세요.
- 진행 상황은 현재 기기의 브라우저에 저장됩니다. 기기 간 자동 동기화는 없습니다.

이 저장소의 `index.html`은 CSS·JavaScript를 포함한 단독 실행 배포본입니다. 다운로드해서 열어도 실행할 수 있습니다. 기본 도트는 임시 아트이고 미기재 타일은 생성 배치입니다.
