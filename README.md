# Vantage Tactics · 소환사의 여정

V2 원본 숫자 데이터를 기반으로 복원 중인 한국어 전술 게임입니다. 30개 고정 맵, 27종 소환사(기본 18직업 포함), 실제 24종 정령의 기본 수치를 적용했습니다. 고유 마법·주야간·성장·이동 취소를 지원하며 일부 전투 계수는 검증 중입니다. [현재 복원 현황](docs/V2_RESTORATION_STATUS.md)을 기준으로 확인하세요.

[PC·모바일에서 플레이](https://etin94-prog.github.io/vantage-tactics/)

## 실행

**`C:\VantageTactics\play.html`을 Chrome 또는 Edge에서 여세요.** 같은 폴더의 `assets/reference-media.js`가 함께 있어야 합니다. 설치·인터넷·서버 없이 동작하며, 최신 Chrome/Edge를 권장합니다. 첫 화면에서 소환사를 선택하고 여정을 시작합니다. 소환사 변경은 원정 지도에서도 가능합니다.

안정적인 자동 저장과 개발용 실행은 Node.js 20 이상에서:

```powershell
cd C:\VantageTactics
npm start
```

`http://127.0.0.1:4173` 접속. 종료는 터미널 Ctrl+C. 저장 공간은 브라우저와 실행 주소별로 분리됩니다. 로컬 파일 모드에서는 브라우저 정책에 따라 저장이 제한될 수 있습니다.

## 플레이

1. 파란 타일로 이동한 뒤 공격·소환·마법·치유 중 하나를 선택합니다. 행동 확정 전에는 **이동 취소** 버튼 또는 **Z**로 원래 위치·방향으로 돌아갑니다. 저장 후 재접속해도 취소할 수 있습니다. 공격·소환·마법·대기 실행 후에는 취소할 수 없습니다.
2. 도감에서 해금된 정령을 고르고 소환사 인접 1칸 안의 빈 타일을 선택합니다. 첫 스크롤은 파·랜셀·레큐·헤피터스·규네포스입니다.
3. 마나는 게임 시간에 따라 정산됩니다(현재 회복량·주기는 임시 규칙). 유지비가 부족하면 소환 비용이 높은 정령부터 소멸합니다.
4. 모든 적 소환사를 쓰러뜨리면 다음 스테이지와 보상 스크롤이 열립니다. 맵 순서는 첫 번째 영상 목록을 따르며 보상은 임시 규칙입니다.

지→수→화→천→지: 우위는 유리하고 역상성·동일 속성은 피해가 줄어듭니다. 최종 피해 변환식은 검증 중입니다. 높이·측후방·지형 방어·근접 반격을 고려하세요. 상단 8회 행동 순서는 기본 공격을 가정한 예측입니다. 실제 행동에 따라 달라집니다.

M 이동 / Z 이동 취소 / A 공격 / S 소환 / D 마법 목록 / H 치유 / Space 대기. 전장 포커스 후 방향키와 Enter로 선택할 수 있습니다. 마우스·터치 드래그, 휠·두 손가락 확대, 현재 유닛을 누르는 빠른 명령 메뉴를 지원합니다. ♫ 버튼으로 원본 MIDI를 브라우저 합성 음색으로 재생하고 WAV 효과음을 켭니다. 옆의 ☷ 버튼에서 19곡 선택과 BGM·효과음 음량을 조절합니다.

## 캐릭터 커스텀

**창작 공방**에서 이름·대표색·PNG/WebP를 변경하고 **변경 적용**을 누릅니다. JSON 내보내기/불러오기로 설정을 보관합니다. 원본 수치는 `src/v2-reference.js`, 이동 특성·임시 해금·외형 연결은 `src/data.js`, 기술은 `src/spells.js`에 있습니다. 원본 수치 파일은 `scripts/export-v2-reference.py`로 생성됩니다. `catalog.js`와 `sync-spec`은 이전 GDD 자료용이며 현재 게임은 이를 사용하지 않습니다.

- 정적 이미지: 투명 PNG/WebP, 권장 48×64 또는 96×128, 최대 2048×2048 및 500KB.
- 애니메이션: 8열 × 6행. 48×64 프레임은 전체 384×384, 96×128 프레임은 768×768.
- 행 순서: Idle 4 / Move 6 / Attack 8 / Cast 6 / Hit 2 / Down 4. 남는 칸은 투명하게 둡니다.
- 방향은 좌우 반전으로 표현합니다. 기본 그림은 코드로 그린 임시 도트 실루엣이며, 전체 캐릭터의 개별 완성 애니메이션 원화는 포함하지 않습니다.

## 맵과 데이터

`data/maps/stage-01.json`부터 `stage-30.json`까지 전장 JSON과 `data/manifest.json`을 제공합니다. 원정 지도 → **맵 JSON 불러오기**로 실행할 수 있습니다. 사용자 맵은 모든 정령을 열어주며 캠페인 기록에 영향을 주지 않습니다.

`data/reference-stage-01.json`은 이전 개발 가이드의 6타일 예시를 보관한 파일입니다. 현재 정규 캠페인은 원본 SC/MD/MP 숫자 레코드에서 얻은 30개 고정 맵을 사용합니다. 첫 전장은 출렁이는 호수이며, 32×32 offset 좌표를 axial 좌표로 변환합니다. 원본의 별도 높이·지형 플래그는 보존하지만 모든 지형 동작이 복원된 것은 아닙니다.

## 개발 및 검증

외부 npm 패키지가 필요 없습니다.

```powershell
npm test              # 33개 테스트, 30전장 AI 합법 행동 검사 포함
npm run check         # 주요 JS 문법 검사
npm run sync-spec     # GDD에서 캐릭터·스테이지 표 재추출
npm run export-maps   # 고정 원본 데이터로 30개 JSON 갱신
npm run build         # 단독 실행 play.html 갱신
```

| 파일 | 역할 |
| --- | --- |
| src/v2-reference.js | 원본 맵·마스터 성장표·정령 숫자 데이터 |
| src/data.js, src/spells.js | 속성·이동·해금·외형·마법 효과 |
| src/hex.js | 축 좌표, 최소 힙, Dijkstra, A* |
| src/engine.js | OA·전투·상태이상·경제·AI·저장 |
| src/maps.js | 고정 맵 로딩·다중 JSON 스키마 정규화·검증 |
| src/renderer.js | Canvas 전장·도트·시트 재생·카메라 |
| src/main.js | 한국어 UI·진행·공방·오디오 |
| docs/SPEC_DECISIONS.md | 문서 간 충돌 및 미정 수치의 구현 결정 |
| docs/V2_RESTORATION_STATUS.md | 현재 복원 근거·미검증 규칙·추가 플레이 실험 |

규칙 변경으로 전투 저장은 v4로 분리했으며 원정의 v3 클리어 기록은 유지합니다. 이전 v1/v2 저장은 삭제하지 않습니다. 기존 18인 외형 설정은 같은 ID로 유지하며, 이전 임시 정령 ID는 새 24종과 자동 연결하지 않습니다. 계정·추적·외부 API·CDN은 사용하지 않습니다.

## 실험·리뷰

[공개 실험실](https://etin94-prog.github.io/vantage-tactics/lab.html)에서 양 팀 수동 행동, 35개 자동 실험, 재현 JSON과 리뷰 내보내기를 지원합니다. 로컬에서는 `lab.html`을 여세요. 다른 Codex 세션과 Claude는 [공통 리뷰 가이드](docs/LAB_REVIEW_GUIDE.md)를 참고하세요. `npm run lab:test`와 `npm run lab:replay -- 파일.json`으로 같은 엔진을 검사할 수 있습니다. `npm run lab:kit`으로 변환된 도트·MIDI·WAV를 포함한 소스·테스트 키트를 생성합니다. 원본 실행 파일과 DAT 압축 파일은 포함하지 않습니다.
